# 开发工具箱

> 本地优先 · 零上传 · 单文件 · 开箱即用的开发者日常工具集

开发工具箱是一个**单 HTML 文件**的开发者工具箱：没有后端、没有依赖、没有构建步骤，下载一个文件双击打开就能用。所有计算全部在浏览器本地完成，**你的数据永远不出本机**——密钥、Token、内网接口、业务 JSON 都可以放心粘贴。

## ✨ 工具一览（4 类 13 个）

### 🛠 开发

- **JSON 格式化** — 校验 + 格式化（自定义缩进）、压缩合并一行、一键生成 TypeScript 接口、可折叠语法树高亮、错误中文定位
- **XML 格式化** — 格式化 / 压缩 / 校验，标签、属性、注释分色高亮
- **HTTPS 调试** — 接口调试：Headers / Query / Body（none、form-data、urlencoded、binary、GraphQL、raw 六种 Body 类型），URL 脏字符自动清洗，一键复制 cURL
- **文本差异对比** — 行级 LCS + 词级高亮，粘贴即对比，原文零改动，万行文件秒级完成
- **正则测试** — 实时匹配、捕获组提取、替换预览、常用正则模板
- **图片 Base64** — 图片转换成 Base64 编码（可粘贴进代码/CSS）、Base64 转换成图片（在线预览、下载），支持 PNG/JPG/WebP/GIF，双向互转，支持拖拽上传

### 🔀 编解码

- **Base64** / **URL 编码** / **Unicode 转换** — 支持中文
- **JWT 解析** — Header / Payload / Signature 分段解析，全程本地

### 🔐 加密

- **哈希计算** — MD5 / SHA-1 / SHA-256 / SHA-512
- **密码生成** — 自定义长度与字符集强度

### 🕐 时间

- **时间戳转换** — 秒 / 毫秒与日期互转

## 🚀 使用方式

**方式一：在线使用**  
直接访问

**方式二：本地使用（推荐，处理敏感数据时）**

1. 下载本仓库的 `index.html`
2. 双击用浏览器打开即可，无需安装任何东西

## 💡 为什么是单文件？

- **隐私**：零上传不是口号——代码里没有任何网络请求，断网也能用
- **便携**：放进 U 盘、丢进网盘、发给同事，一个文件搞定
- **可审计**：全部代码就在一个文件里，10 分钟可以读完，没有黑盒

## 🖥 适用场景

- 开发 / 调试时的日常格式化、编解码
- 处理包含敏感信息的配置与接口数据
- 内网环境 / 无外网环境下的离线工具
- 给不想装一堆在线网站书签的同事安利
